# ECController {{TAG}}

这一版把「登录后自动应用」从"只能挑一个模式"改成了**按功能组分别勾选**，
为此新增了**电池管理**功能组支持、**保存配置**按钮与逐项反馈，并重构了界面外观。

## 下载

| 文件 | 说明 |
|---|---|
| `ECController-1.0.1-win-x64.zip` | 完整发布包（程序 + EC 配置 + 驱动 + 许可证） |
| `SHA256SUMS.txt` | 附件校验和，建议下载后核对 |

解压后目录结构：

```

├─ ECController.exe            主程序（已声明 requireAdministrator）
├─ ECController.exe.config     运行时配置
├─ Data\ec ADDRESS.txt         可用模式定义（文本，可自行编辑扩展）
├─ Drivers\WinRing0x64.sys     Ring0 端口访问驱动

```

**运行要求**：Windows 10 / 11 x64，写入 EC 时须以管理员身份运行（双击会自动弹 UAC）。

## 本版新增

### 1. 按功能组分别设置开机后应用的内容

`Data\ec ADDRESS.txt` 里的功能组彼此独立（性能模式写 `0x78/0x79`，电池管理写 `0xE4/0xE5`），
登录后可以同时应用「性能模式 = Hunter3」和「电池管理 = 70%」——旧版只能二选一。

界面上的「启动后应用以下配置」区域现在**为每个功能组各生成一行**：一个复选框 + 一个该组的模式下拉框。
行是按配置文件动态生成的，以后往 `ec ADDRESS.txt` 里加新的 `[功能组]`，界面自动多一行，不用改代码。

### 2. 新增「电池管理」功能组

`ec ADDRESS.txt` 现在示例配置了两个组：

| 功能组 | 模式 | 写入 |
|---|---|---|
| 性能模式 | 智能模式 / Hunter1–Hunter5 | `0x78`、`0x79` |
| 电池管理 | 关闭功能 / 70% / 90% / 100% | `0xE4`、`0xE5` |

> `0xE4/0xE5` 的取值因机型而异，**默认内容仅作示例**，写入前请先点「读取当前 EC」核对现值。

### 3. 「保存配置」按钮与逐项反馈

设置项改动不再"改一下就悄悄生效"，而是先在内存里标记为未保存（右侧提示
「有未保存的更改」），点「保存配置」后才落盘。保存时三件事分别确认、分别报告：

1. **config.json** —— 写入成功与否，并列出完整路径；
2. **开机启动项** —— 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
   （关闭时是移除），随后**回读注册表比对**，明确写「与预期一致 / 与预期不一致」；
3. **登录后行为** —— 用一句话说清楚登录时到底会发生什么，
   包括「已启用自动应用但没有勾选任何功能组，实际不会写入 EC」这种容易误判的情况。

任何一项失败，标题栏提示都会变成「配置保存未完全成功」，不会给出"看起来成功了"的模糊反馈。

关闭窗口时若仍有未保存的改动，会先询问是否保存（可取消退出）。

### 4. 界面重构

- **微软雅黑**：字体优先使用「微软雅黑」，不可用时回退 Segoe UI（结果会记进日志，便于排查）。
- **Mica 效果**：标题栏在 Windows 11 22H2（build ≥ 22621）及以上启用系统 Mica 材质，
  并设置圆角与（深色模式下）深色标题栏。
- **客户区底纹**：客户区跟随窗口位置读取桌面壁纸、强模糊后叠加浅色光罩铺底。
  **这一部分是模拟，不是真正的系统材质** —— 纯 WinForms 的客户区拿不到 DWM 背景材质，
  实测确认只有非客户区（标题栏）能透出真 Mica。因此这里明说：标题栏为真，客户区为仿。
- 卡片高度随功能组行数自动增长，窗口随之调整，不会出现内容被裁切或按钮越界。

### 5. 配置向后兼容

旧版 `config.json`（单一 `BootGroup` / `BootMode`）会在读取时自动迁移为新的
`BootSelections` 数组，并**沿用旧的「启动后应用」开关取值**——旧配置里没开启的，
迁移后依然关闭，不会因为存在模式记录就凭空打开。

## 已知限制

- `Data\ec ADDRESS.txt` 中的地址与取值因机型而异，默认内容面向荣耀 Hunter 系列。
- 直接读写 EC 属于未经厂商授权的底层操作，可能影响风扇转速、功耗墙、充电策略等硬件行为。
  **电池管理的寄存器写入会实际改变充电上限，请确认地址与取值后再用。**
- 客户区底纹是壁纸模糊模拟；窗口快速拖动时会重算底纹，低端机可能有轻微跟手延迟。
- 本项目按 **GPL-3.0** 分发（因依赖并分发 GPL-3.0 的 WinRing0）。
  闭源商业使用须先移除 WinRing0 相关部分，详见包内 `LICENSE` 与 `README.md`。
