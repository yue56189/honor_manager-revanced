这一版是**性能修复版**：界面本身没变样，但把上一版引入的一处严重卡顿改掉了。

## 上一版卡在哪

1.0.1 的客户区底纹是**读桌面壁纸 → 强模糊 → 叠浅色光罩**合成的一张位图，
用来模拟 Mica 质感。问题是账单很贵（实测 Windows 11 build 26200 / DPI 125%）：

| 环节 | 耗时 |
|---|---|
| 合成一次底纹（读文件 + 解码 + 两次重采样） | **49.5 ms** |
| 位图贴回客户区 | 7.1 ms / 帧 |
| **拖动窗口（每移动 10px 重做一次上两项）** | **87 ms / 帧（约 7 FPS）** |

也就是说，只要动一下窗口就是 7 帧/秒，肉眼必然觉得卡。
更不划算的是：那张图经过强模糊和 0.86 不透明度的光罩之后，**本身就几乎是一块均匀浅色**——
花 49.5 ms 去算一块近乎纯色的底。

## 本版做了什么

### 1. 客户区底纹换成纯色垂直渐变

去掉整条"壁纸 → 模糊 → 光罩"的链路，改为一次渐变的直接填充。

| 环节 | 1.0.1 | 1.0.2 |
|---|---|---|
| 背景生成 | 49.5 ms（每次移动窗口都要重做） | **0.6 ms**（按需填充，移动窗口**零**额外开销） |
| 拖动窗口（每次位移 10px） | 87 ms | **1.19 ms** |
| 整窗重绘 | 35.2 ms | ~30 ms |

背景变成很淡的上浅下深渐变（`#FAFBFD` → `#E9EEF4`），观感与原来那块模糊底几乎没有区别——
这一点是**按像素核对**过的，不是目测。

### 2. 修掉透明容器引起的重复绘制

「启动后应用」区域的行容器原来设成 `BackColor = Transparent`。
透明容器每次重绘都要请父级把它那块区域重画一遍，而它里面的复选框也是透明的，
于是**每个子控件重绘都会再触发一次父级重绘**。实测这一块单独占去整窗重绘 35 ms 里的 13.5 ms。
它整块落在白色卡片内部，本来就该是不透明的白——改成卡片白之后这一项降到 8.8 ms。

### 3. 绘制对象改为缓存复用

- 字体、圆角路径、画笔、画刷不再每次重绘重新创建，全部按尺寸/颜色缓存。
  （原先 `OnPaint` 里直接调用返回新实例的字体属性，等于每次重绘都新建若干 GDI+ 对象。）
- 顺带确认：原写法不会泄漏 GDI 句柄（`Font` 有终结器，实测 300 次重绘 GDI 对象增量 0），
  但会持续制造垃圾。改成缓存后连这份 GC 压力也没有了。

### 4. 关于 Mica

- **标题栏的真 Mica 保留**（Windows 11 22H2 / build ≥ 22621 及以上）。
  这一项由 DWM 合成器绘制，**不占本进程 CPU**，把它一起砍掉只是白白损失观感。
- 想彻底关掉窗口材质，把 `config.json` 里的 `MicaTitleBar` 改成 `false` 即可
  （窗口圆角与深色标题栏仍会保留）。旧配置里没有这一项时默认开启，无需手工添加。
- 客户区那套"壁纸模糊模拟"已整条移除——它本来就是仿的，且正是卡顿的来源。

### 5. 新增性能探针

新增 `PerfProbe` 测试套件（6 项），把上述指标固化成可重复的断言：
背景填充耗时、拖动每次位移耗时、整窗重绘耗时、GDI 对象增量。
以后再有人动界面代码，跑一遍就知道有没有把性能改回去。

## 剩余的 30 ms 是什么

整窗重绘还有约 30 ms，但它不是这套自绘代码的问题，而是**原生控件的固有成本**：

| 项 | 耗时 | 说明 |
|---|---|---|
| 4 个 ComboBox（纯原生绘制部分） | 8.9 ms | 系统控件，换成纯原生也只快这么多 |
| 4 个 ComboBox 的自绘圆角/箭头补画 | 4.2 ms | 本项目的代码，占 32% |
| 窗体自身（渐变 + 标题 + 分隔线） | 5.2 ms | |
| 卡片 / 按钮 / 复选框 / 明细表等 | 其余 | |

这个数字只在"强制整窗同步重绘"时出现（改窗口大小、从最小化恢复、被遮挡后重现），
日常操作（悬停、点击、下拉、拖动窗口）都只重绘单个控件或完全不重绘。
如果哪天想把它也压下去，方向是减少原生控件数量，而不是继续抠自绘代码。

## 已知限制

- `Data\ec ADDRESS.txt` 中的地址与取值因机型而异，默认内容面向荣耀 Hunter 系列。
- 直接读写 EC 属于未经厂商授权的底层操作，可能影响风扇转速、功耗墙、充电策略等硬件行为。
  **电池管理的寄存器写入会实际改变充电上限，请确认地址与取值后再用。**
- 界面交互手感（鼠标点击、悬停反馈、关窗时的未保存提示）由程序化断言覆盖几何与配色，
  但**没有做自动化的真实点击冒烟**，建议首次使用时手动过一遍。
- 本项目按 **GPL-3.0** 分发（因依赖并分发 GPL-3.0 的 WinRing0）。
  闭源商业使用须先移除 WinRing0 相关部分，详见包内 `LICENSE` 与 `README.md`。
