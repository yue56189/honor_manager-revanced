# ECController {{TAG}}

首个正式版本。一个通过读写笔记本 **EC（Embedded Controller）** 寄存器来切换性能模式的
Windows 桌面工具，界面为 Fluent Design 风格自绘，不带任何第三方 UI 依赖。

## 下载

| 文件 | 说明 |
|---|---|
| `ECController-1.0.0-win-x64.zip` | 完整发布包（程序 + EC 配置 + 驱动 + 许可证） |
| `SHA256SUMS.txt` | 附件校验和，建议下载后核对 |

解压后目录结构：

```
ECController-1.0.0/
├─ ECController.exe            主程序（已声明 requireAdministrator）
├─ ECController.exe.config     运行时配置
├─ Data\ec ADDRESS.txt         可用模式定义（文本，可自行编辑扩展）
├─ Drivers\WinRing0x64.sys     Ring0 端口访问驱动
├─ LICENSE                     GPL-3.0
├─ THIRD-PARTY-NOTICES.txt     第三方组件声明
└─ README.md
```

**运行要求**：Windows 10 / 11 x64，必须以管理员身份运行（双击会自动弹 UAC）。

## 功能

- **EC 读写**：通过 WinRing0 驱动直接读写 EC 寄存器，不依赖厂商电源管理软件。
- **配置驱动**：所有可用模式由 `Data\ec ADDRESS.txt` 定义，改文本即可扩展，无需改代码。
- **写入校验**：写入后自动回读并逐地址显示 `✔ 一致` / `✘ 不一致`。
- **登录自动应用**：登录后按设定延迟自动套用指定模式，静默运行不打扰。
- **开机启动**：写入 HKCU `Run` 项，无需管理员即可开关。
- **托盘常驻**：最小化到托盘，支持「显示主界面 / 重新应用 / 退出」。
- **驱动自愈**：服务 `ImagePath` 失效时自动修正，驱动缺失时给出可操作提示。
- **日志**：按天写入 `Logs\yyyy-MM-dd.log`，出错可直接复制给他人排查。

## 本版重点修复

1. **EC 读数串扰**（重要）。端口 `0x62/0x66` 与系统 ACPI EC 驱动、厂商电源软件共享，
   单次读数不可信——实测写后连读 4 次可能得到 `[错, 对, 对, 错]`。
   现在采用**连续两次读数一致才认可**的策略（最多重试 10 次），不再把碰巧相等的
   串扰值当成写入成功。同时写入后固定等待 200 ms 再回读，避免误报不一致。
2. **界面元素重叠 / 文字重影**。根因是自绘控件的 `ControlStyles.Opaque` 未关闭，
   导致双缓冲图面被反复复用、上一帧像素残留；同时卡片 `BackColor` 与实际绘制色不一致，
   在透明子控件处留下形状等于控件矩形的灰补丁。已改为显式擦背景并统一底色。
3. **下拉框双箭头**。原生下拉箭头与自绘 V 形箭头重叠，现先覆盖右端再绘制。

## 已知限制

- `Data\ec ADDRESS.txt` 中的地址与取值因机型而异。默认内容面向荣耀 Hunter 系列，
  其它机型需自行确认地址后再写入。
- 直接读写 EC 属于未经厂商授权的底层操作，可能影响风扇转速、功耗墙、充电策略等硬件行为。
- 本项目按 **GPL-3.0** 分发（因依赖并分发 GPL-3.0 的 WinRing0）。
  闭源商业使用须先移除 WinRing0 相关部分，详见包内 `LICENSE` 与 `README.md`。
